# Revisión Docker del 25 de noviembre de 2026

Base revisada: `origin/main`, commit `6583ec4` de GitHub. Cambios en
`codex/actualizacion-de-docker`, sin modificar main ni abrir un PR.

## Problemas reproducidos y correcciones

- El bloque principal usaba `--no-recreate`: construía una imagen nueva pero
  conservaba el contenedor antiguo. Ahora permite la actualización y usa `--wait`
  para comprobar el healthcheck antes de anunciar disponibilidad.
- El puerto 3000 estaba ocupado por una instancia anterior. Compose admite ahora
  `APP_PORT`, manteniendo 3000 por defecto y sin detener otras instalaciones.
- Compose no transmitía `ADMIN_EMAIL`, `ADMIN_PASSWORD` y `POSTGRES_PASSWORD`.
  Ahora permite configurar las credenciales de una instalación nueva. Las cuentas
  y contraseñas persistidas siguen teniendo prioridad al reiniciar.
- Con `POSTGRES_PASSWORD=short`, el supervisor ejecutaba initdb antes de validar.
  El siguiente arranque fallaba por falta de `db-password`. También se podía
  persistir una contraseña inicial inválida del administrador. Ahora valida ambas
  configuraciones antes de inicializar la base y guarda la contraseña de PostgreSQL
  antes de initdb. No borra ni reinicializa bases existentes.
